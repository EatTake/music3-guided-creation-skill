# 歌词母稿与适配规则

## 母稿是唯一文字来源

中文歌词先形成母稿，再映射到 Music3 文档。母稿段落包含稳定的本地 `id`、可读 `label` 和完整 `lines`。不要在母稿中写 UUID、推理参数、唱法括注或编曲命令。

```json
{
  "song_id": "example-v1",
  "language": "zh-CN",
  "sections": [
    {
      "id": "verse-1",
      "label": "主歌一",
      "lines": ["清晨的门轻轻响", "风把纸页翻到下一行"]
    }
  ]
}
```

## 权限

- `none`: 只检查和适配，不改任何正文。
- `selected`: 只改用户指定的位置或目标。
- `full`: 可以整体修改，但仍保留逐位置锁定句。

诊断不等于改词授权。用户已经确认的原句不能因为押韵、密度或模型提示而被静默修改。

## 写作与检查

按以下顺序检查：

1. 事实来源与锁定原句。
2. 叙述视角、对象和时间关系。
3. 每段是否增加新信息。
4. 副歌重复是否有目的，结尾是否成立。
5. 自然语序、句长、换气和拗口连读。
6. 韵脚与记忆句；意思优先于押韵。
7. 目标长度对应的素材密度；只提示风险，不用公式保证秒数。
8. 原创性；不复制参考作品的辨识度高措辞、意象组合或故事。
9. 旋律适配；没有可读取的旋律时标记未验证。

状态使用 `pass`、`needs_revision`、`unverified`、`not_applicable`。

## 段落映射

只使用以下标签：

`Intro` `Verse` `Pre-Chorus` `Chorus` `Post-Chorus` `Bridge` `Instrumental` `Solo` `Outro`

“主歌一”映射为 `Verse`，标题保留“主歌一”；“最后副歌”映射为 `Chorus`。无法判断用途的自定义段名先询问，不发明新标签。

每次副歌完整展开。不能使用“同上”“副歌×2”或类似占位。适配时逐字复制母稿的 `lines`，含标点、大小写和重复次数。

空器乐段使用 `instrumental=true`、`lines=[]`；有人声段使用 `instrumental=false` 且至少一行正文。段落演唱和编曲要求写进 `music_intent`。

## 锁定

锁定记录使用母稿段落 ID、从 0 开始的行号和完整文字：

```json
{
  "section_id": "verse-1",
  "line_index": 0,
  "text": "清晨的门轻轻响"
}
```

重复句按每个位置分别锁定。歌词变化必须回到母稿建立新版本，再重新适配；不能只改生成输入。

## 能力边界

文本检查不能证明实际演唱逐字一致、音高正确或情绪到位。没有音频理解证据时，听检状态必须写未验证。局部改一行后重新生成也不能保证其他旋律或音频保持不变。
